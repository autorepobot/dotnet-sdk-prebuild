# .NET SDK Prebuild

Prebuilt .NET SDK packages for Linux architectures not covered by the standard .NET SDK releases.

Currently available for:

* x86
* x64
* ARM64
* RISC-V 64
* LoongArch64
* PPC64LE

## Downloads

See the [Releases](../../releases) page for prebuilt SDK archives.

Each release includes SHA-256 checksums for verification.

## Purpose

These packages are mainly used for building and testing .NET applications, including **Avalonia** applications, on additional Linux architectures.
